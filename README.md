# Fecha Libre

Webapp para salir de deudas: ordena deudas y cuotas, calcula la fecha libre y exporta los vencimientos al calendario. Todo corre en el navegador; los datos quedan en el dispositivo (localStorage).

- `app-ar/`: Argentina (voseo, ARS)
- `app/`: español neutro
- `landing-ar/`, `landing/`: páginas de venta
- `test/`: autochequeos

Sitio estático, sin build. Servir cada carpeta tal cual; `vendor/` (pdf.js y fuentes) debe ir junto a `index.html`.
